path_or_web_url_validator(type_: object, path_or_url: Path | str) → str

Validate that the provided path is either a valid local path or a web URL.

NOTE: Path(“”) resolves to the current directory (“.”) - which is considered a valid path.

Parameters:

  • type (object) – The type of the argument being validated - unused, purely required for cyclopts validator compatibility.

  • path_or_url (Path | str) – The candidate path or URL to validate.

Returns:

The validated path or URL as a string.

Return type:

str

Raises:

ValueError – If the provided path is neither a valid local path nor a web URL.

save_geo_zarr(ds: Dataset, zarr_path: Path | str, target_chunk_size: str = '1024MB') → None

Save dataset to GeoZarr adhering to CF conventions (https://cfconventions.org/).

Parameters:

  • ds (xr.Dataset) – The xarray dataset to save. This must follow the GeoZarr format, including having a spatial_ref attribute with a valid CRS.

  • zarr_path (Path | str) – Full path of the output .zarr file to be created.

  • target_chunk_size (str, optional) – The target chunk size for the GeoZarr dataset, by default “1024MB”.
